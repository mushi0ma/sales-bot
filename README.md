# sales-bot

Тестовая среда для «ИИ-агента продаж для ЖКХ» (WhatsApp-бот, позже звонки) на базе open-source стека fazer.ai.

- `docs/SETUP.md` — как развернуть (появится после фазы 1–3)
- `infra/` — скрипты создания ВМ (libvirt/QEMU+KVM, cloud-init)

Секреты лежат только в локальном `.env` (в `.gitignore`). Только тестовые данные.
