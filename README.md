# sales-bot

ИИ-агент продаж e-KNOT для ЖКХ (практика AITU). Бот читает тестовую WhatsApp-группу жильцов, находит потребности,
которые закрывают услуги [eknot.me](https://eknot.me), и пишет автору в личку с подходящей услугой. Отдельно работает
бот поддержки жильцов (заявки, показания счётчиков, справочник). Модели: Gemini на Vertex AI. Только тестовые данные.

## Как проверить

- Адрес: https://sales-bot.eknot.kz (Chatwoot, рабочее место оператора; вход выдаётся по запросу).
- Тестовая группа WhatsApp: в описании группы сказано, что сообщения читает бот. Напишите в группу о проблеме
  дома, например «Половина дома не платит взносы, на ремонт крыши денег нет». В течение 1–3 минут бот напишет
  вам в личку с предложением услуги e-KNOT. Ответьте ему, он продолжит разговор. «стоп» отключает сообщения.
- Бот поддержки: личка того же номера (отвечает только отмеченным тестировщикам).

## Как устроено

```
WhatsApp-группа ─ WhatsApp Web (whatsmeow) ─ Chatwoot ─ вебхук ─ group-watcher ─ LiteLLM ─ Gemini (Vertex AI)
                                                │                     │
                                                │   карточка оператору, сообщение в личку (путь A)
                                                └─ ответ жильца ─ fazer.ai agents (Gemini Flash, база знаний, проверка фактов)
```

| Путь | Что |
|---|---|
| `stack/group-watcher/` | поиск потребностей в группах и предложения в личку: фильтр по словам ru/kk, пачка сообщений в Gemini Flash-Lite раз в минуту, правила отправки (отказ «стоп», 1 предложение в 7 дней, тихие часы 21–09, лимит в день) |
| `stack/group-watcher/services.json` | 7 услуг eknot.me и Аудитор ЖКХ (zhkh.zerde.site): что дают, признаки потребности, текст предложения; из него же база знаний продавца |
| `stack/kb/` | снимки страниц услуг eknot.me для базы знаний продавца; `refresh.py` раз в неделю показывает, что изменилось на сайте |
| `stack/litellm/config.yaml` | единый вход к Gemini, жёсткие лимиты запросов в минуту и в день на каждую модель |
| `stack/bootstrap.py` | настройка Chatwoot и agents: агент, инструменты, база знаний, вебхуки |
| `stack/agent/` | промпты продавца и бота поддержки, справочник УК |
| `stack/tests/` | сценарии через настоящий конвейер agents: 14 для бота поддержки, 12 для продавца |
| `deploy/` | деплой на ВМ Google Cloud через IAP, секреты из Secret Manager, ночной бэкап в Cloud Storage |

Проверки: `python3 -I stack/group-watcher/test_watcher.py` (логика без сети);
на ВМ `docker compose exec group-watcher python3 -I /app/watcher.py eval /app/samples.json` (точность и полнота
распознавания), `python3 -I tests/scenarios.py` (бот поддержки) и `python3 -I tests/scenarios.py --seller` (продавец).
Цифры для ежедневного отчёта: `docker compose exec group-watcher python3 -I /app/watcher.py report [дней]` (воронка от
сообщения в группе до лида, доставка, ответы за 24 ч, отказы).

Секреты только в Google Secret Manager. В репозитории их нет.
