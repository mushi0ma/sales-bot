# Грант Google Cloud: что запросить у тех. отдела

Бот ЖКХ (WhatsApp, потом звонки). Работаем из Казахстана, общаемся по-русски, позже, возможно, по-казахски.
Данные собраны с официальных страниц Google 2026-11-12. Перед подачей заявки цены и квоты сверить заново.
Пометка **«не подтверждено»** означает, что официального источника не нашлось.

> Vertex AI переименован в **Gemini Enterprise Agent Platform**. Документация теперь на
> `docs.cloud.google.com/gemini-enterprise-agent-platform/…`, API-хост прежний: `aiplatform.googleapis.com`.
> Ниже для краткости — «Vertex».

## 0. Главное: через что бот будет ходить в Gemini

В нашем стеке fazer.ai `agents` Google подключается так (`vendor/agents/src/graph/models.ts`, `BehaviorTab.tsx`):

| Функция | Провайдеры в agents | Как ходит в Google |
|---|---|---|
| Ответы (LLM) | `google` (+ openai, openai-compatible, anthropic, deepseek) | `ChatGoogleGenerativeAI` → **Gemini Developer API (AI Studio)**, ключ в заголовке `x-goog-api-key` |
| Голосовые → текст (STT) | `gemini`, openai, openai-compatible, elevenlabs, openrouter | Gemini Developer API |
| Фото, документы (vision) | `gemini`, openai, openai-compatible, anthropic, openrouter | Gemini Developer API |
| Ответ голосом (TTS) | openai, elevenlabs, openrouter | **Google нет** |
| Эмбеддинги (RAG) | только OpenAI-совместимый `/embeddings`, колонка жёстко 1536 измерений | без патча нельзя: agents не передаёт `dimensions` |

**Вывод.** «Из коробки» agents работает с **ключом AI Studio (Gemini API)**, а не с Vertex. Возникает развилка, решить её надо с тех. отделом:

1. **Ключ Gemini API** на проекте, привязанном к биллинг-аккаунту с кредитами.
   - Плюс: ничего не дорабатываем.
   - Минус: Gemini API работает по Prepay (минимум $5). Списываются ли **стартап-кредиты** на Gemini API, **не подтверждено**: в документации сказано, что «eligible» Cloud-кредиты списываются, только пока Prepay-баланс больше 0. Welcome credit $300 и Free Trial на Gemini API не действуют.
2. **Vertex**: кредиты точно применяются (Agent Platform входит в «Google Cloud products, PayG»).
   - Минус: agents не умеет Vertex напрямую. Нужен прокси в нашем стеке — OpenAI-совместимый эндпоинт Vertex и OAuth-токен сервисного аккаунта, который обновляется каждый час.
   - Будет ли работать статический API-ключ Vertex («express mode») для нужных моделей — **не подтверждено**. Спросить.

**Просьба к тех. отделу:** подтвердить, покрывают ли кредиты гранта Gemini API (AI Studio, Prepay). Если нет — выдать Vertex и сервисный аккаунт, и тогда мы сделаем прокси.

## 2. Квоты

- **Vertex Standard PayGo:** квота на уровне организации, порог TPM зависит от трат за последние 30 дней.
  - Flash и Flash-Lite: Tier 1 ($10–250) — 2M TPM, Tier 2 — 4M, Tier 3 — 10M.
  - Pro: 500K, 1M, 2M TPM соответственно.
  - Это не жёсткий лимит: при перегрузке общего пула бывает 429. Пулы `eu`, `us` и отдельных регионов меньше, чем у `global`.
- **Gemini API (AI Studio):** уровни по оплатам.

  | Уровень | Условие | Потолок трат | Лимит за 10 мин |
  |---|---|---|---|
  | Tier 1 | привязан биллинг | $250 | $10 |
  | Tier 2 | оплачено $100 + 3 дня | $2 000 | — |
  | Tier 3 | оплачено $1 000 + 30 дней | — | — |

  RPM и TPM по моделям видны только в консоли (**не подтверждено**). Лимит $10 за 10 минут на Tier 1 для продакшена тесен.
- **Наша нагрузка (оценка):** текст — пик ~20 RPM × 4K ≈ **80K TPM**, этого хватает с запасом даже на Tier 1. Звонки — пик **5–10 одновременных Live-сессий**.
- Мультимодальные лимиты по умолчанию (изображения 34M, аудио 11M, документы 1.2M токенов) повышает только account team.

## 3. Данные и регионы (Казахстан)

- **Доступность:** Казахстан есть в списке стран Gemini API, России нет. Официального списка стран для Vertex и GCP не нашлось.
- **Регионы:** регионов GCP в Казахстане нет.
  - Ближайший вариант с гарантией обработки в ЕС — мультирегион **`eu`** (`aiplatform.eu.rep.googleapis.com`).
  - `global` даёт максимальную ёмкость, но обработка может идти в любой стране.
  - Live доступен только в `us` и `eu`.
- **Обучение:** Vertex не обучается на данных клиента. Бесплатный тариф **AI Studio обучается и может показывать данные людям**, поэтому реальные данные жильцов туда не отправлять. На платном тарифе не обучается, но промпты временно логируются для abuse monitoring.
- **Чтобы данные не хранились (ZDR):**
  - не включать request-response logging;
  - не включать session resumption в Live;
  - решить, отключать ли кэширование (хранится до 24 ч);
  - не использовать Grounding with Google Search.
- **Закон РК о персональных данных** (локализация баз ПДн) — **нужна проверка юристом**. На практике база ПДн хранится у нас, а в Gemini уходит минимум данных (ИИН и телефоны маскируем).

## 4. Оценка затрат в месяц

**Допущения:**
- 10 000 диалогов × 8 ответов = 80 000 вызовов LLM;
- на вызов: ~4 000 токенов входа и ~300 выхода;
- 2 000 голосовых по 20 с;
- 1 000 фото;
- 2 000 звонков по 3 мин.

| Статья | Модель | ≈ $/мес |
|---|---|---|
| Текст | 3.8 Flash (2026) | 330 (с кэшем ≈ 220; с 2027 — 660) |
| Текст, вариант Lite | 3.5 Flash-Lite | 156 |
| Голосовые | прямо в 3.8 Flash | ≈ 1 (через Transcribe — 3.4, через Chirp 3 — 10.7) |
| Фото | 3.8 Flash | ≈ 1 |
| Эмбеддинги | embedding-001 | ≈ 1.4 |
| Звонки, вариант Live | 3.8 Live | 85–300 |
| Звонки, вариант STT → LLM → TTS | Transcribe Live + Flash-Lite + Flash-Lite TTS | ≈ 115 |

**Итого:** в 2026 году **≈ $280–650/мес**, с 2027-го (Flash и TTS дорожают вдвое) **≈ $800–1 000/мес**. Endpoint `eu` добавляет 10%. Телефония (SIP, Voximplant) и WhatsApp BSP сюда не входят.
